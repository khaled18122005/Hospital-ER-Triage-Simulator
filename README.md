# 🏥 Hospital ER & Triage Simulation Engine (C++)

A time-step simulation system for managing hospital emergency room workflows, patient triage, and doctor scheduling using custom data structures.

## 🛠️ Tech Stack & Concepts
* **Language:** C++ (OOP, Pointers, Memory Management, File I/O)
* **Data Structures:** Priority Queue (Max-Heap), FIFO Queue, Singly Linked List, Binary Search Tree (BST)

## 📂 Project Architecture
    Hospital-ER-Triage-Simulator/
    ├── include/
    │   ├── DataStructures/   # Custom generic data structures (Node, Queue, PriorityQueue, BST)
    │   └── Models/           # System entities (Patient, Doctor, HospitalScheduler)
    ├── src/                  # Implementation files (.cpp) and main entry point
    └── data/                 # Simulation input scenarios & generated analytical reports

- [ ] **Phase 1:** Implementing Core Generic Data Structures (`Queue`, `PriorityQueue`)
- [ ] **Phase 2:** Building System Entities (`Patient`, `Doctor`) & Triage Priority Formula
